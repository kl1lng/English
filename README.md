# Discover Kazakhstan — 30-Day Speaking Booster

Веб-приложение для взрослых, которые хотят каждый день практиковать разговорный английский (уровень B1–B2). Тема — Казахстан: 30 уроков, запись ответов с письменной обратной связью, повторение слов, диалог с ИИ-собеседником, игры, уровни и значки. Регистрация самостоятельная, без школ и кабинета учителя.

Подробная карта проекта и текущие ограничения: [`PROJECT_MAP.md`](PROJECT_MAP.md). План последних доработок: [`docs/superpowers/plans/2026-11-14-engagement-and-ai-speaking.md`](docs/superpowers/plans/2026-11-14-engagement-and-ai-speaking.md).

## Что умеет

- **30 уроков** о местах, истории и традициях Казахстана: факт, вопросы для речи, шесть слов с переводом на казахский и русский, озвучка слов.
- **Запись ответа** и письменная обратная связь (Cloudflare Whisper распознаёт речь, Groq или Cloudflare Llama пишет разбор). Аудио не хранится. Произношение и баллы IELTS не оцениваются.
- **Повторение слов** по алгоритму FSRS: карточки «вспомни», «вставь слово», «послушай».
- **Диалог с ИИ-собеседником**: 8 сценариев, голосовые реплики, итоговый разбор. Хранится только разбор.
- **Игры**: найди пару, собери предложение.
- **Привычка**: серия дней (урок или 10 повторов слов), заморозка серии, XP, уровни, значки, дневная цель.
- **Напоминания в Telegram** (по желанию, нужен бот).

## Запуск локально

Нужен Node.js 20 или новее.

```powershell
npm install
npm run dev
```

Откройте <http://localhost:5173>. `npm run dev` запускает Vite (интерфейс) и Express (локальный API). Без ключей Supabase приложение работает в демо-режиме: профиль «Antoshka» и данные в браузере (localStorage).

```powershell
npm test        # тесты логики и API-хелперов (Vitest)
npm run build   # сборка фронтенда в dist/
npm start       # Express отдаёт собранное приложение на порту 3001
```

## Настройка

1. Скопируйте `.env.example` в `.env` и заполните нужное. `.env` в git не попадает. Секреты не кладите в `src/` и в переменные с префиксом `VITE_`, кроме публичных значений Supabase.
2. В Supabase выполните по порядку файлы из `supabase/migrations/` (`001` … `005`) и `supabase/schema.sql`, если проект новый. Пока миграция не выполнена, соответствующий раздел показывает «ещё не настроено», остальное работает.
3. Переменные описаны в `.env.example`; для Vercel секреты задаются в настройках проекта.

## Структура

| Путь | Назначение |
|---|---|
| `src/main.jsx` | Основной интерфейс: вход, дашборд, уроки, запись, отзыв, чат |
| `src/components/` | Повторение слов, достижения, диалог, игры |
| `src/lib/` | Чистая логика с тестами: повторы (SRS), серия, XP, значки, игры |
| `src/hooks/` | Колода слов, XP и значки, привязка Telegram |
| `src/lessons.js`, `src/data/scenarios.js` | 30 уроков и сценарии диалогов |
| `api/` | Функции Vercel: health, feedback, chat, dialogue, dialogue-summary, telegram, remind |
| `server/` | Общие серверные модули: проверка входа, квоты, ИИ-вызовы; локальный Express |
| `supabase/` | Схема и миграции |
| `public/audio/` | 181 запись произношения слов |

## Деплой

GitHub `kl1lng/English`, ветка `main`; пуш в `main` запускает деплой Vercel (проект `30english`). В `vercel.json` есть ежедневный cron для напоминаний: проверьте, что тариф его допускает. Приложение можно перенести на свой сервер: функции из `api/` — обычные обработчики запроса и ответа, их можно подключить к Express (как это сделано для диалога в `server/index.js`).

## Ограничения

- Проверка входа, квоты и ИИ-функции не проверены с боевыми ключами; напоминания в Telegram не запускались с реальным ботом.
- XP и значки считаются на клиенте и подлежат правке самим пользователем; общая лига потребует серверного начисления.
- Казахские переводы не проверены носителем.
- Старый код локального Express с регистрацией и JSON-хранилищем (`/api/auth/*`, `/api/submissions`) не используется фронтендом.
