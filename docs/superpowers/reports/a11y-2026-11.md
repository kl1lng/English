# Accessibility pass, 2026-11-15

Method: axe-core 4.14 (WCAG 2.0 A/AA and 2.1 AA rules) on the seven main pages (dashboard, journey, word review, word games, speaking partner, level and badges, certificate) in the light and dark theme, demo mode, desktop width, transitions disabled. Plus automated contrast checks of the design tokens (`src/lib/contrast.test.js`).

## Found and fixed
| Finding | Fix |
|---|---|
| 3 icon-only buttons without a name (`mini-add`, `profile-more`, `circle-nav`) | `aria-label` added |
| Muted text `#8c99a8` on white 2.9:1 (used for labels and captions) | `--muted` now `#5e7086` (5.1:1) |
| Orange logo text `#ed9a69` on white 2.2:1 | new token `--accent-text` (`#b4531c` light, `#f6a778` dark) |
| Blue text 3.1 to 3.8:1 (links, active menu item, "see all") | new token `--link` (`#2a62b8` light, `#7fb0f5` dark) |
| Filled blue button with white text 3.4:1 (`primary-cta`) | uses `--primary-strong` (5.2:1) |
| Warm grey text 3.1:1 in the streak pill | uses `--text-muted` |
| `--success-strong` 4.38:1 on its light background | darkened to `#287560` |
| Decorative "a–z" text flagged | `aria-hidden="true"` |
| No skip link, no `aria-current`, unnamed navigation | skip link to `#content`, `aria-current="page"`, `nav aria-label="Main"` |
| Mobile menu: no Escape, focus not returned | Escape closes the menu and focuses the menu button |

Result: no axe violations on the seven pages in either theme.

## Not checked
- Keyboard walkthrough with a real keyboard on every page (only the tab order start was checked in the DOM: the skip link is the first focusable element).
- Screen reader (NVDA, VoiceOver): needs a person.
- Modals (lesson, sign-in, chat) in axe, and states that only appear after actions (review session cards, dialogue conversation).
- 200% browser zoom.
