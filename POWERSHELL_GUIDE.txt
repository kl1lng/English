================================================================================
  ИНСТРУКЦИЯ ПО ЗАПУСКУ ПРОЕКТА "ANTOSHKA" ЧЕРЕЗ POWERSHELL (WINDOWS)
================================================================================

1. ТРЕБОВАНИЯ К СИСТЕМЕ
--------------------------------------------------------------------------------
Для работы проекта необходима среда выполнения Node.js (версия 20 или новее).
Проверьте установку, выполнив в PowerShell:

    node -v
    npm -v

Если Node.js не установлен:
- Скачайте с официального сайта: https://nodejs.org
- Либо установите через терминал PowerShell:
    winget install OpenJS.NodeJS.LTS


2. КАК ОТКРЫТЬ ПРОЕКТ В POWERSHELL
--------------------------------------------------------------------------------
Вариант А (через команду перехода):
Откройте PowerShell (Win + R -> powershell -> Enter) и выполните:

    cd "C:\Users\kulda\Documents\Antoshka"

Вариант Б (через Проводник Windows):
1. Откройте папку C:\Users\kulda\Documents\Antoshka в Проводнике.
2. В адресной строке вверху сотрите путь, напишите: powershell
3. Нажмите Enter — терминал сразу откроется в нужной папке.


3. УСТАНОВКА ЗАВИСИМОСТЕЙ (ПРИ ПЕРВОМ ЗАПУСКЕ)
--------------------------------------------------------------------------------
Если вы только склонировали проект или удалили node_modules, выполните:

    npm install

(Если зависимости уже установлены, этот шаг можно пропустить).


4. ОСНОВНОЙ ЗАПУСК В РЕЖИМЕ РАЗРАБОТКИ (РЕКОМЕНДУЕТСЯ)
--------------------------------------------------------------------------------
Выполните команду:

    npm run dev

Что происходит при этой команде:
- Запускается одновременно фронтенд (Vite / React) и бэкенд (Node.js Express API).
- Веб-интерфейс доступен по адресу: http://localhost:5173
- API сервер доступен по адресу: http://localhost:3001

Чтобы сразу открыть приложение в браузере по умолчанию из PowerShell:

    Start-Process http://localhost:5173


5. КАК ОСТАНОВИТЬ СЕРВЕР
--------------------------------------------------------------------------------
- В окне PowerShell, где запущен проект, нажмите сочетание клавиш:
    Ctrl + C
- При запросе подтверждения завершения пакета введите Y и нажмите Enter.

Если процессы Node.js зависли или не освободили порты в фоне:

    Stop-Process -Name node -Force


6. ДОПОЛНИТЕЛЬНЫЕ РЕЖИМЫ ЗАПУСКА
--------------------------------------------------------------------------------
А) Сборка и запуск Production-версии:
    npm run build
    npm start
    (Приложение будет доступно на http://localhost:3001)

Б) Раздельный запуск (в двух отдельных окнах PowerShell):
    В первом окне (только веб-клиент Vite):
        npm run dev:web
    Во втором окне (только сервер API):
        npm run server


7. НАСТРОЙКА OPENAI (НЕОБЯЗАТЕЛЬНО)
--------------------------------------------------------------------------------
Приложение полностью работает и без OpenAI API ключа (в режиме локального демо).
Если вам нужен реальный AI-фидбек:
1. Создайте файл .env на основе шаблона:
    Copy-Item .env.example .env
2. Откройте файл .env и укажите ваш ключ:
    OPENAI_API_KEY=ваш_ключ
3. Перезапустите dev-сервер (Ctrl + C, затем npm run dev).


8. РЕШЕНИЕ ЧАСТЫХ ПРОБЛЕМ
--------------------------------------------------------------------------------
Ошибка: "Выполнение сценариев отключено в этой системе" (Execution Policy):
Выполните в PowerShell команду для текущей сессии:
    Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

Ошибка: "Порт 5173 или 3001 уже занят":
Проверьте занятые порты:
    Get-NetTCPConnection -LocalPort 5173, 3001 -ErrorAction SilentlyContinue
Завершите все зависшие процессы Node.js:
    Stop-Process -Name node -Force
Затем снова выполните:
    npm run dev
